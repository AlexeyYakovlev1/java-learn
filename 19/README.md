# Что такое `enum` и зачем он нужен?
enum (сокращение от enumeration) — это специальный вид класса, который представляет фиксированный набор именованных констант. 
Он появился в Java 5 и заменил старый приём с полями `public static final`, который не обеспечивал типобезопасности и позволял создавать произвольные значения.

Ключевые характеристики `enum`:
- Фиксированный набор экземпляров: Компилятор знает все возможные значения перечисления. Создать экземпляр `enum` за пределами списка констант невозможно.
- Типобезопасность: В метод, ожидающий enum, нельзя передать произвольное значение (в отличие от `int` или `String`), что исключает целый класс ошибок.
- Полноценный класс: `enum` может содержать поля, конструкторы и методы, что позволяет связывать с каждой константой дополнительные данные и поведение.
- Неявное наследование от `java.lang.Enum`: Все перечисления автоматически наследуются от этого класса и реализуют интерфейсы `Comparable` и `Serializable`.
```java
public enum DayOfWeek {
    MONDAY, TUESDAY, WEDNESDAY, THURSDAY, FRIDAY, SATURDAY, SUNDAY
}
```
Соглашение об именовании: Константы enum принято записывать ПРОПИСНЫМИ БУКВАМИ с подчёркиваниями между словами.
```java
DayOfWeek today = DayOfWeek.MONDAY; // обращение по имени типа
// создавать через new нельзя: DayOfWeek day = new DayOfWeek(); // ошибка!
```

## Встроенные методы
Компилятор автоматически добавляет в каждый `enum` несколько полезных методов:
- `values()`: Массив всех констант в порядке объявления	`DayOfWeek.values()` → `[MONDAY, ..., SUNDAY]`
- `valueOf(String name)`: Константу по её имени (с учётом регистра)	`DayOfWeek.valueOf("MONDAY")` → `DayOfWeek.MONDAY`
- `name()`: Имя константы в виде строки	`DayOfWeek.MONDAY.name()` → `"MONDAY"`
- `ordinal()`: Порядковый номер (с нуля)	`DayOfWeek.MONDAY.ordinal()` → `0`

Важное предостережение: `valueOf()` выбрасывает `IllegalArgumentException`, если строки с таким именем нет. 
Кроме того, `ordinal()` зависит от порядка объявления — не сохраняйте это число в базу данных, так как при изменении порядка констант оно станет неверным

## Поля, конструкторы и методы
`enum` может иметь поля и конструкторы. Это позволяет связать с каждой константой дополнительные данные. 
Конструктор `enum` всегда неявно является `private` — его нельзя вызвать извне.
```java
public enum Planet {
    MERCURY(3.303e+23, 2.4397e6),
    VENUS(4.869e+24, 6.0518e6),
    EARTH(5.976e+24, 6.37814e6);

    private final double mass;   // в килограммах
    private final double radius; // в метрах

    // Конструктор неявно private
    Planet(double mass, double radius) {
        this.mass = mass;
        this.radius = radius;
    }

    public double surfaceGravity() {
        return 6.67300E-11 * mass / (radius * radius);
    }
}
```

Переопределение методов для отдельных констант: Каждая константа может иметь собственное тело и переопределять методы. 
Это позволяет реализовать разное поведение для разных значений.
```java
public enum Operation {
    PLUS {
        public double apply(double x, double y) { return x + y; }
    },
    MINUS {
        public double apply(double x, double y) { return x - y; }
    };

    public abstract double apply(double x, double y);
}
```

## Использование в `switch`
`enum` идеально подходит для `switch`, так как компилятор может проверить исчерпывающность (exhaustiveness) — все ли возможные значения обработаны. 
В `switch`-выражениях (Java 14+) отсутствие `default` для `enum` не является ошибкой, если обработаны все константы.
```java
// В switch-выражении компилятор проверяет, что все константы покрыты
String type = switch (day) {
    case SATURDAY, SUNDAY -> "Выходной";
    case MONDAY, TUESDAY, WEDNESDAY, THURSDAY, FRIDAY -> "Рабочий день";
};
```

# Специализированные коллекции: `EnumSet` и `EnumMap`
Для работы с наборами `enum` существуют две высокоэффективные реализации коллекций:
- `EnumSet`: Специализированная реализация `Set`, внутренне использующая битовый вектор. Операции выполняются очень быстро, а память расходуется минимально.
- `EnumMap`: Реализация `Map`, где ключи — это `enum`. Также оптимизирована для максимальной производительности.
```java
EnumSet<DayOfWeek> weekend = EnumSet.of(DayOfWeek.SATURDAY, DayOfWeek.SUNDAY);

EnumMap<DayOfWeek, String> schedule = new EnumMap<>(DayOfWeek.class);
schedule.put(DayOfWeek.MONDAY, "Планирование");
```

# `enum` как реализация Singleton
`enum` с единственной константой — это самый надёжный и лаконичный способ реализовать паттерн «Одиночка» (Singleton) в Java.
Он автоматически обеспечивает потокобезопасность и корректную десериализацию, защищая от создания второго экземпляра через рефлексию — проблем, с которыми сталкиваются традиционные реализации.
```java
public enum Singleton {
    INSTANCE;

    public void doSomething() {
        System.out.println("Единственный экземпляр в деле!");
    }
}

// Использование:
Singleton.INSTANCE.doSomething();
```
