# Что такое `static`?
`static` — это не-модификатор доступа (non-access modifier), который делает переменную, метод, блок или вложенный класс принадлежащим классу, а не конкретному объекту (экземпляру) этого класса.
Проще говоря: обычные члены класса принадлежат объектам, а static-члены — самому классу, и существуют в единственном экземпляре, независимо от того, сколько объектов создано

## Статические поля (Class Variables)
Статическое поле — это переменная, объявленная с модификатором `static`. Существует в единственном экземпляре на весь класс, независимо от количества созданных объектов
```java
public class Counter {
    static int instances = 0; // статическое поле — одно на всех
    int id;                   // instance-поле — своё у каждого

    Counter() {
        instances++; // каждый объект увеличивает общий счётчик
        id = instances;
    }
}
```
Ключевые особенности:
- Создаётся один раз при загрузке класса.
- Разделяется всеми экземплярами класса.
- Инициализируется до создания любого объекта.
- Доступ: `ИмяКласса.имяПоля` (предпочтительно) или через ссылку на объект (не рекомендуется).

Частое применение: константы (`static final`), счётчики, общие настройки.

## Статические методы (Class Methods)
Статический метод — это метод, объявленный с модификатором `static`. Вызывается через имя класса, без создания объекта
```java
public class MathUtils {
    public static int add(int a, int b) {
        return a + b;
    }
}

// Вызов без создания объекта
int result = MathUtils.add(5, 3);
```
- Не может обращаться к instance-полям и instance-методам напрямую, так как в статическом контексте нет объекта `this`.
- Может обращаться к статическим полям и вызывать статические методы.
- Не может использовать ключевое слово `this` и `super`.

## Статические блоки инициализации
Статический блок — это блок кода, выполняемый один раз при загрузке класса в память (до вызова `main` и до создания объектов).
```java
public class Config {
    static String dbUrl;
    static String dbUser;

    static {
        // выполняется один раз при загрузке класса
        dbUrl = "jdbc:mysql://localhost:3306/mydb";
        dbUser = "admin";
        System.out.println("Класс Config загружен");
    }
}
```

## Статический импорт
Статический импорт (`import static`) позволяет использовать статические члены класса без указания имени класса.
```java
import static java.lang.Math.PI;
import static java.lang.Math.cos;

public class Test {
    public static void main(String[] args) {
        double r = cos(PI * 2); // без Math.
    }
}
```
