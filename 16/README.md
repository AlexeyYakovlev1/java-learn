# Что такое полиморфизм?
Полиморфизм (от греч. «много форм») — это способность объекта принимать разные формы и вести себя по-разному в зависимости от его фактического типа.
В Java полиморфизм достигается через наследование и переопределение методов.

Ключевая идея: переменная родительского типа может ссылаться на объект любого из своих подклассов. 
При вызове переопределённого метода будет выполнен тот вариант, который определён в фактическом классе объекта, а не в типе ссылки.

## Как это работает: динамическое связывание
Когда вы вызываете метод через ссылку, Java определяет, какую именно реализацию использовать, во время выполнения, а не во время компиляции. 
Этот механизм называется динамическим (поздним) связыванием (dynamic / late binding).
```java
class Animal {
    public void makeSound() {
        System.out.println("Какое-то животное издаёт звук");
    }
}

class Dog extends Animal {
    @Override
    public void makeSound() {
        System.out.println("Гав!");
    }
}

class Cat extends Animal {
    @Override
    public void makeSound() {
        System.out.println("Мяу!");
    }
}

public class Demo {
    public static void main(String[] args) {
        Animal myAnimal = new Dog(); // ссылка типа Animal, объект Dog
        myAnimal.makeSound();        // Выведет "Гав!" (фактический тип — Dog)

        myAnimal = new Cat();        // теперь ссылка указывает на Cat
        myAnimal.makeSound();        // Выведет "Мяу!"
    }
}
```
Компилятор видит только тип ссылки `Animal`, но JVM во время выполнения определяет, что объект на самом деле является `Dog` или `Cat`, и вызывает соответствующую реализацию.

# Приведение типов (Casting)
Приведение типов — это преобразование ссылки одного типа в ссылку другого типа внутри одной иерархии наследования. Существует два направления:

### Восходящее приведение (Upcasting)
Upcasting — это преобразование ссылки на подкласс в ссылку на родительский класс.

- Выполняется неявно (автоматически) компилятором.
- Всегда безопасно — объект подкласса всегда «является» объектом родительского класса.
- Именно оно делает возможным полиморфизм.
```java
Dog myDog = new Dog();
Animal myAnimal = myDog; // неявный upcasting
// или сразу:
Animal myAnimal = new Dog(); // тоже upcasting
```
Ограничение: через ссылку родительского типа доступны только те методы и поля, которые объявлены в родительском классе. 
Специфичные методы подкласса вызвать нельзя.

### Нисходящее приведение (Downcasting)
Downcasting — это преобразование ссылки родительского типа обратно в ссылку на подкласс.

- Требует явного указания типа в скобках: `(Подкласс) ссылка`.
- Может быть небезопасным — если фактический объект не является экземпляром указанного подкласса, во время выполнения возникнет `ClassCastException`.
- Необходимо, когда нужно вызвать методы, специфичные для подкласса.
```java
Animal myAnimal = new Dog(); // upcasting
Dog myDog = (Dog) myAnimal;  // downcasting — явное приведение
myDog.fetch();               // теперь доступен метод fetch() из Dog
```
Когда нужен downcasting: если у вас есть коллекция объектов `Animal`, но для некоторых из них нужно вызвать метод, которого нет в `Animal`, а есть только в конкретном подклассе.

# Оператор instanceof: безопасное приведение
Чтобы избежать `ClassCastException` при downcasting, используется оператор `instanceof`. 
Он проверяет, является ли объект экземпляром указанного типа (или его подтипа), и возвращает `boolean`.
```java
Animal myAnimal = new Dog();

if (myAnimal instanceof Dog) {
    Dog myDog = (Dog) myAnimal; // безопасно — проверка пройдена
    myDog.fetch();
}
```
