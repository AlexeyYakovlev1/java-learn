# Циклы
В Java существует четыре основных вида циклов:
- `while` - цикл с предусловием (условие проверяется до тела поэтому может не выполниться ни разу)
- `do-while` - цикл с постусловием (условие проверяется после тела, поэтому выполнится хотя бы один раз)
- `for` - цикл с счётчиком (кол-во итераций обычно известно заранее)
- `for-each` - расширенный цикл для перебора элементов массива или коллекции

## `for`
```java
for (инициализация; условие; итерация) {
    // тело цикла
}

for (int i = 1; i <= 5; i++) {
    System.out.println("Счёт: " + i);
}
```

## `while`
```java
while (условие) {
    // тело цикла
}

int count = 1;
while (count <= 5) {
    System.out.println("Счёт: " + count);
    count++; // Важно: изменение переменной, чтобы условие когда-то стало false
}
```

## `do-while`
```java
do {
    // тело цикла
} while (условие); // Обратите внимание на точку с запятой в конце!

int count = 1;
do {
    System.out.println("Счёт: " + count);
    count++;
} while (count <= 5);
```

## `for-each`
```java
for (Тип переменная : коллекция_или_массив) {
    // тело цикла
}

int[] numbers = {1, 2, 3, 4, 5};
for (int num : numbers) {
    System.out.println(num);
}
```

# Управление циклом: `break` и `continue`
- `break` - прерывает цикл
- `continue` - пропускает текущую итерацию и переходит к следующей

```java
int[] numbers = {1, 5, 8, 12, 15};
int searchFor = 12;
boolean found = false;

for (int i = 0; i < numbers.length; i++) {
    if (numbers[i] == searchFor) {
        found = true;
        break; // Число найдено, дальше искать нет смысла
    }
}
```

# Метки (labels) для вложенных циклов
Если циклы вложены друг в друга, `break` и `continue` по умолчанию действуют только на самый внутренний цикл. 
Чтобы управлять внешним циклом, можно использовать метки.
```java
search: // Метка для внешнего цикла
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        if (i == 1 && j == 1) {
            break search; // Прервать внешний цикл
        }
        System.out.println(i + ", " + j);
    }
}
```
