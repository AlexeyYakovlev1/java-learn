# Краткое введение
JDK (Java Development Kit) - это полный набор инструментов для разработки на Java.
JRE (Java Runtime Environment) - это среда, необходимая для запуска уже готовых Java-программ.
JVM (Java Virtual Machine) - это сердце Java, виртуальная машина, которая выполняет Java-байткод.

# Расширенное описание
## JDK (Java Development Kit) - Комплект разработки Java
JDK - это инструмент для разработчиков. Он включает в себя все, что есть в JRE, плюс набор инструментов для создания, компиляции и отладки Java-программ. Ключевые инструменты в составе JDK:

- Компилятор (javac): Преобразует твой исходный код (.java) в байткод (.class).
- Отладчик (jdb): Позволяет отлаживать Java-программы.
- JRE: Для запуска и тестирования созданных Java-программ.
- Другие утилиты: Например, jar для упаковки классов в архивы, javadoc для создания документации и тд.

## JRE (Java Runtime Environment) - Среда выполнения Java
JRE - это то, что нужно установить на пк, если ты хочешь просто запускать Java-программы, но не разрабатывать их.
JRE можно представить как "контейнер", который предоставляет все необходимое для работы JVM.
Вот что входит в состав JRE:

- JVM: Виртуальная машина Java, которая выполняет байткод
- Стандартные библиотеки Java
- Служебные компоненты: Различные файлы и системные компоненты, необходимые для корректного запуска приложений

## JVM (Java Virtual Machine) - Виртуальная машина Java
Отвечает за принцип Java - написал один раз - запускай где угодно.
Когда компилируешь Java-код, создается не машинный код для конкретного процессаора, а универсальный байткод (файлы .class).
JVM затем интерпретирует или компилирует этот байткод в машинные инструкции, понятные твоей ОС.

- Загрузка кода: Загружает скомпилированные файлы в память
- Проверка безопасности: Проверяет байткод на наличие опасных операций перед выполнением
- Управление памятью: Автоматически распределяет память для объектов
- Сборка мусора (Garbage Collection): Автоматически удаляет объекты, которые больше не используются в программе, освобождая память
- Выполнение: Преобразует байткод в машинные инструкции и выполняет их


# Резюме
| Компонент | Для кого? | Что делает? | Что включает? |
| :--- | :--- | :--- | :--- |
| **JDK** | Разработчики | **Пишет** код | JRE + Инструменты разработки (компилятор `javac`, отладчик `jdb` и т.д.) |
| **JRE** | Пользователи | **Запускает** код | JVM + Стандартные библиотеки Java |
| **JVM** | Код | **Выполняет** код | Является частью JRE, выполняет байт-код |
