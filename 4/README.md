# Арифметические операторы
Эти операторы выполняют привычные математические действия

| Оператор | Описание | Пример (при `a = 10`, `b = 3`) | Результат |
| :--- | :--- | :--- | :--- |
| `+` | Сложение (и конкатенация строк) | `a + b` | `13` |
| `-` | Вычитание | `a - b` | `7` |
| `*` | Умножение | `a * b` | `30` |
| `/` | Деление | `a / b` | `3` (целочисленное) |
| `%` | Остаток от деления (модуль) | `a % b` | `1` |

Важный нюанс: при делении целых чисел результат тоже будет целым, дробная часть отбрасывается.
Чтобы получить дробный результат, хотя бы один из операндов должен быть числом с плавающей точкой.
```java
int a = 10;
int b = 3;

System.out.println(a / b); // 3
System.out.println(10.0 / 3); // 3.3333333333333335
```

## Унарные арифметические операторы
Кроме бинарных, есть операторы, работающие с одним операндом.
- `++` (инкримент) и `--` (декримент) увеличивают или уменьшают значение переменной на 1.
- `+` (унарный плюс) и `-` (унарный минус) указывают знак числа 1.
```java
int x = 5;
int y = x++; // Постфиксная форма: y = 5, затем x = 6
int z = ++x; // Префиксная форма: x = 7, затем z = 7
```

# Операторы сравнения
Эти операторы сравнивают два значения и всегда возвращают результат типа `boolean`.
- `==` (равно)
- `!=` (не равно)
- `<` (меньше)
- `>` (больше)
- `<=` (меньше или равно)
- `>=` (больше или равно)
```java
int a = 5;
int b = 10;
System.out.println(a < b); // true
```

# Логические операторы
Логические операторы работают с булевыми значеними (true, false) и используются для построения сложных условий.
- `&&` (логическое И)
- `||` (логическое ИЛИ)
- `!` (логическое НЕ)
```java
boolean a = true;
boolean b = false;
System.out.println(a && b); // false
```

## Тернарный оператор
Тернарный оператор `? :` позволяет записать простое условие в одну строку.
```java
int a = 5;
int b = 10;
int max = (a > b) ? a : b; // max = 10
```
