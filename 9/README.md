# Что такое класс и объект?
Класс — это «чертёж» или «шаблон», который описывает, какие поля (данные) и методы (поведение) будут у объектов этого класса.
Объект — это конкретный экземпляр класса, созданный по этому «чертежу». Объект обладает состоянием (значениями полей) и поведением (методами).

Аналогия: Класс `Car` — это чертёж автомобиля. Объекты `myCar`, `yourCar` — это конкретные машины, созданные по этому чертежу. У каждой машины свой цвет, скорость и пробег, но все они умеют ехать и тормозить.

## Объявление класса
```java
модификатор_доступа class ИмяКласса {
    // поля (состояние)
    // конструкторы
    // методы (поведение)
}
```
```java
public class Car {
    // Поля (переменные экземпляра)
    String brand;
    String color;
    int speed;

    // Метод (поведение)
    void accelerate() {
        speed += 10;
        System.out.println(brand + " ускоряется. Скорость: " + speed);
    }

    void brake() {
        speed -= 10;
        System.out.println(brand + " тормозит. Скорость: " + speed);
    }
}
```

## Создание объекта
Объект создаётся с помощью оператора new, который выделяет память и вызывает конструктор:
```java
Car myCar = new Car(); // создание объекта
myCar.brand = "Toyota"; // доступ к полю через точку
myCar.color = "Red";
myCar.speed = 0;

myCar.accelerate(); // вызов метода
```

# Конструктор
Конструктор — это специальный метод, который вызывается при создании объекта. Его имя совпадает с именем класса, и он не имеет возвращаемого типа (даже `void`).

Виды конструкторов:
- Конструктор по умолчанию: если вы не объявили ни одного конструктора, Java автоматически создаёт пустой конструктор без параметров.
```java
public class Car {
    String brand;
    // Конструктор по умолчанию создаётся автоматически
}
```
- Параматеризованный конструктор: позволяет задат начальные значения полей при создании
```java
public class Car {
    String brand;
    String color;
    int speed;

    // Параметризованный конструктор
    public Car(String brand, String color) {
        this.brand = brand;   // this.brand — поле класса
        this.color = color;   // brand — параметр метода
    }
}

// Использование
Car myCar = new Car("Toyota", "Red");
```
Ключевое слово `this` используется для ссылки на текущий объект. Оно помогает различить поле класса и параметр метода, если у них одинаковые имена.
- Перегрузка конструкторов: можно объявить несколько конструкторов с разными параметрами.
```java
public class Car {
    String brand;
    String color;
    int speed;

    public Car() {
        this("Unknown", "Unknown"); // вызов другого конструктора
    }

    public Car(String brand, String color) {
        this.brand = brand;
        this.color = color;
        this.speed = 0;
    }

    public Car(String brand, String color, int speed) {
        this(brand, color); // вызов конструктора с двумя параметрами
        this.speed = speed;
    }
}
```

# Модификаторы доступа
Модификаторы доступа определяют, какие части программы могут обращаться к полям и методам класса.
- `public`: доступен из любого места.
- `private`: доступен только внутри класса.
- `protected`: доступен внутри класса и его подклассов.
- `default` (без модификатора): доступен только внутри пакета.
Рекомендация: поля класса обычно делают private, а доступ к ним предоставляют через методы (геттеры и сеттеры). Это принцип инкапсуляции.

# Инкапсуляция: геттеры и сеттеры
Инкапсуляция - это сокрытие внутреннего состояния объекта и предоставление контролируемого доступа к нему.
```java
public class Car {
    private String brand;
    private int speed;

    public Car(String brand) {
        this.brand = brand;
        this.speed = 0;
    }

    // Геттер (getter) — для чтения значения
    public String getBrand() {
        return brand;
    }

    // Сеттер (setter) — для изменения значения
    public void setBrand(String brand) {
        this.brand = brand;
    }

    public int getSpeed() {
        return speed;
    }

    public void accelerate() {
        if (speed < 200) { // контроль скорости
            speed += 10;
        }
    }
}
```

### Зачем это нужно:
- Защита данных от некорректных изменений.
- Возможность добавить валидацию в сеттерах.
- Скрытие деталей реализации.

# Сборщик мусора
Когда объект больше не используеся (на него нет ссылок), он становится доступен для сборщика мусора (Garbage Collector).
Java автоматически освобождает память, поэтому вручную управлять памятью не нужно.
```java
Car myCar = new Car("Toyota", "Red");
myCar = null; // объект больше не доступен, будет удалён сборщиком мусора
```
