# Что такое массив?
Массив — это контейнер, который хранит фиксированное количество элементов одного и того же типа. 
Все элементы массива располагаются в памяти последовательно и имеют индексы, начиная с нуля.

## Ключевые характеристики:
- Фиксированная длина: после создания массив не может быть изменен в размерах.
- Однотипность: все элементы массива должны быть одного типа (примитивного или ссылочного).
- Индексация: элементы массива доступны по индексу, начиная с 0, последний - `длина - 1`.
- Ссылочный тип: сам массив является объектом, даже если хранит примитивы.

# Одномерные массивы
## Объявление и создание
```java
// Способ 1: Объявление с последующим созданием
int[] numbers;              // объявление ссылки
numbers = new int[5];       // создание массива на 5 элементов

// Способ 2: Объявление и создание в одной строке
int[] numbers = new int[5];

// Способ 3: Инициализация значениями (размер определяется автоматически)
int[] numbers = {10, 20, 30, 40, 50};

// Альтернативный синтаксис (менее предпочтительный)
int numbers[]; // скобки после имени
```

Важно: при создании массива через `new` все элементы автоматически инициализируются значениями по умолчанию: `0` для чисел, `false` для boolean, `null` для ссылочных типов.

## Доступ к элементам
```java
int[] numbers = {10, 20, 30, 40, 50};

int first = numbers[0];      // 10
int third = numbers[2];      // 30
numbers[1] = 25;             // изменение значения

int length = numbers.length; // 5 (длина массива)
```

Важно: опытка обратиться к индексу за пределами массива вызовет `ArrayIndexOutOfBoundsException`.

# Многомерные массивы
## Объявление и создание
```java
// Прямоугольный массив 3x4 (3 строки, 4 столбца)
int[][] matrix = new int[3][4];

// Инициализация значениями
int[][] matrix = {
    {1, 2, 3, 4},    // строка 0
    {5, 6, 7, 8},    // строка 1
    {9, 10, 11, 12}  // строка 2
};

// Доступ к элементу
int value = matrix[1][2]; // 7 (строка 1, столбец 2)
```

Структура в памяти: `matrix` - это массив из 3 элементов. Каждый из этих элементов - ссылка на массив из 4 чисел.
Поэтому `matrix.length` возвращает 3 (количество строк), а `matrix[0].length` возвращает 4 (длина первой строки).

# "Рваные" (jagged) массивы
Java позволяет создавать массивы, где каждая строка имеет разную длину.
```java
// Объявление без указания размеров строк
int[][] jagged = new int[3][];

// Каждую строку создаём отдельно
jagged[0] = new int[] {1, 2};
jagged[1] = new int[] {3, 4, 5};
jagged[2] = new int[] {6, 7, 8, 9};

// Или сразу с инициализацией
int[][] jagged = {
    {1, 2},
    {3, 4, 5},
    {6, 7, 8, 9}
};
```
При создании `new int[3][]` внешний массив создаётся, но его элементы (строки) изначально равны `null` и должны быть инициализированы отдельно.

# Класс `Arrays`: полезные утилиты
Java предоставляет класс java.util.Arrays со статическими методами для работы с массивами:

| Метод | Описание |
| :--- | :--- |
| `Arrays.toString(array)` | Возвращает строковое представление одномерного массива |
| `Arrays.deepToString(array)` | Возвращает строковое представление многомерного массива |
| `Arrays.sort(array)` | Сортирует массив (для примитивов — по возрастанию) |
| `Arrays.binarySearch(array, key)` | Бинарный поиск элемента (массив должен быть отсортирован) |
| `Arrays.equals(a, b)` | Сравнивает содержимое двух массивов |
| `Arrays.deepEquals(a, b)` | Сравнивает содержимое многомерных массивов |
| `Arrays.fill(array, value)` | Заполняет весь массив указанным значением |
| `Arrays.copyOf(original, newLength)` | Копирует массив с возможным изменением длины |
| `Arrays.copyOfRange(original, from, to)` | Копирует диапазон массива |
| `Arrays.asList(array)` | Преобразует массив в список (фиксированного размера) |

```java
import java.util.Arrays;

int[] numbers = {5, 2, 8, 1, 9};

System.out.println(Arrays.toString(numbers)); // [5, 2, 8, 1, 9]

Arrays.sort(numbers);
System.out.println(Arrays.toString(numbers)); // [1, 2, 5, 8, 9]

int index = Arrays.binarySearch(numbers, 5); // 2

int[] copy = Arrays.copyOf(numbers, 3); // [1, 2, 5]
```

## Сравнение массивов
Оператор `==` сравнивает ссылки (адреса в памяти), а `equals()` для массивов не переопределён и ведёт себя так же.
```java
int[] a = {1, 2, 3};
int[] b = {1, 2, 3};

System.out.println(a == b);            // false (разные объекты)
System.out.println(a.equals(b));       // false (то же самое)

System.out.println(Arrays.equals(a, b)); // true (сравнение содержимого)
```

Для многомерных массивов используйте `Arrays.deepEquals()`.
