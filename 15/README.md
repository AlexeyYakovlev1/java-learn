# Что такое наследование?
Наследование — это механизм, позволяющий одному классу (наследнику, подклассу) перенимать поля и методы другого класса (родителя, суперкласса). 
Это реализует отношение «является» (is-a): `Truck` является `Car`, `Cat` является `Animal`.
Зачем это нужно: Если у нескольких классов есть общие свойства и поведение, их можно вынести в один родительский класс, а наследники будут использовать их, не дублируя код.

Важно: каждый класс в Java неявно наследуется от класса Object — это корень всей иерархии.

## Ключевое слово `extends`
Наследование в Java реализуется через ключевое слово `extends`. 
В отличие от некоторых других языков, Java поддерживает только одиночное наследование — у класса может быть только один прямой родитель.
```java
public class Car {
    private String model;
    private int maxSpeed;

    public Car(String model, int maxSpeed) {
        this.model = model;
        this.maxSpeed = maxSpeed;
    }

    public void gas() {
        System.out.println("Машина ускоряется!");
    }
}

// Truck наследуется от Car
public class Truck extends Car {
    public Truck(String model, int maxSpeed) {
        super(model, maxSpeed); // вызов конструктора родителя
    }
}
```
Теперь `Truck` имеет доступ ко всем не-приватным полям и методам `Car`.

## Ключевое слово `super`
`super` — это ссылка на родительский класс. У него есть три основных применения:
### 1. Вызов конструктора родителя (`super(...))`)
Когда вы создаёте объект наследника, конструктор родителя всегда выполняется первым. 
Если у родителя нет конструктора без параметров, вызов `super(...)` в конструкторе наследника обязателен, и он должен быть первой строкой:
```java
public Truck(String model, int maxSpeed) {
    super(model, maxSpeed); // первая строка!
    // затем инициализация собственных полей Truck
}
```
Если конструктор наследника не вызывает `super(...)` явно, компилятор автоматически вставляет вызов `super()` — конструктора родителя без параметров.

### 2. Доступ к переопределённому методу родителя
Если наследник переопределил метод, но хочет вызвать его реализацию из родителя, используется `super.имяМетода()`:
```java
public class Truck extends Car {
    @Override
    public void gas() {
        super.gas(); // вызов реализации Car
        System.out.println("Но грузовик делает это громче!");
    }
}
```

### 3. Доступ к полю родителя
Аналогично: `super.имяПоля` позволяет обратиться к полю родителя, если в наследнике есть поле с таким же именем.

## Переопределение методов (Overriding)
Переопределение — это замена реализации метода родителя собственной версией в наследнике.
Метод наследника должен иметь тот же набор параметров и совместимый тип возвращаемого значения.
```java
public class Animal {
    public void makeSound() {
        System.out.println("Какое-то животное издаёт звук");
    }
}

public class Cat extends Animal {
    @Override
    public void makeSound() {
        System.out.println("Мяу!");
    }
}
```

### Аннотация `@Override`
Аннотация `@Override` не обязательна, но настоятельно рекомендуется. 
Она говорит компилятору, что вы намереваетесь переопределить метод родителя. 
Если компилятор не найдёт такого метода (например, из-за опечатки в имени), он выдаст ошибку.

Правила переопределения
- Сигнатура должна совпадать (имя + параметры).
- Тип возвращаемого значения должен быть тем же или ковариантным (подтипом).
- Модификатор доступа нельзя сужать. Если метод родителя `protected`, в наследнике он может быть `protected` или `public`, но не `private`.
- `final`-методы переопределить нельзя.
- `private`-методы не наследуются и, следовательно, не переопределяются.
- Статические методы не переопределяются — они скрываются (hiding).

## Ограничения наследования
- Нет множественного наследования классов. Java позволяет наследовать только от одного класса.
- `final`-классы нельзя наследовать (`String`, `Integer` и др.).
- `private`-члены родителя недоступны наследнику напрямую.
- Конструкторы не наследуются — их нужно вызывать явно через `super(...).`
