# Переменные: что это и зачем нужны
Переменная - это именованная область в памяти, которая хранит значение определенного типа.
Java - статически типизированный язык, поэтому перед использованием переменной необходимо объявить ее тип.
```java
тип имяПеременной = начальноеЗначение;
```
```java
int age = 25; // целое число
double price = 19.99; // число с плавающей точкой
char grade = 'A'; // символ
boolean isActive = true; // логическое значение
```
Если переменная не инициализирована, компилятор выдаст ошибку при попытке использовать ее.

# Восемь примитивных типов данных
Java поддерживает весемь примитивных типов. Примитивные значения не разделяют состояние с другими примитивами и хранят само значение, а не ссылку на объект.

| Тип | Размер | Диапазон / Значения | Назначение |
| :--- | :--- | :--- | :--- |
| **`byte`** | 8 бит | от −128 до 127 | Экономия памяти в больших массивах |
| **`short`** | 16 бит | от −32 768 до 32 767 | Экономия памяти в больших массивах |
| **`int`** | 32 бита | от −2³¹ до 2³¹−1 | Целые числа по умолчанию |
| **`long`** | 64 бита | от −2⁶³ до 2⁶³−1 | Очень большие целые числа |
| **`float`** | 32 бита | ±1.4E−45 … ±3.4E+38 | Дробные числа (экономия памяти) |
| **`double`** | 64 бита | ±4.9E−324 … ±1.7E+308 | Дробные числа по умолчанию |
| **`char`** | 16 бит | от 0 до 65 535 (Unicode) | Один символ |
| **`boolean`** | — | `true` или `false` | Логические значения |

## Целочисленные типы (`byte`, `short`, `int`, `long`):
- `int` - самый используемый целочисленный тип в Java.
- `long` - нужен когда значения выходят за пределы `int`. Литералы типа `long` заканчиваются символом `L`.
- `byte` и `short` - применяются в основном для экономии памяти в массивах.

## Типы с плавающей точкой (`float`, `double`):
- `float` - Литералы типа `float` заканчиваются символом `f` или `F`.
- `double` - Тип по умолчанию для дробных чисел. Литералы типа `double` заканчиваются символом `d` или `D`.

Важно: ни float, ни double не подходят для точных вычислений (например, финансовых расчетов). Для этого используется класс `BigDecimal`.

## Символьный тип (`char`):
- `char` - Тип для хранения символов. Литералы типа `char` обрамляются одинарными кавычками.- `char` - Может хранить Unicode символы.

## Логический тип (`boolean`):
- `boolean` - Тип для хранения логических значений.- `boolean` - Значения `true` и `false` используются для логических операций.

# Литералы и именование
Литералы - это фактические значения, записанные прямо в коде.
```java
int count = 100; // 100 - литерал
double ratio = 0.5; // 0.5 - литерал
char symbol = '#'; // # - литерал
String text = "Hello"; // "Hello" - литерал
```

# Ключевые моменты
## Переполнение (overflow)
```java
int b = 127;
b++; // становится -128 (циклический переход)
```

## Неявное и явное приведение типов
```java
int i = 100;
long l = i; // неявно (расширяющее приведение) - безопасно
double d = i; // неявно

double pi = 3.14;
int truncated = (int) pi; // явно (сужающее) - 3, дробная часть теряется
```

## Дефолтные значения
Локальные переменные не получают значений по умолчанию - их нужно инициализировать вручную. Поля класса инициализируются автоматически (0, 0.0, false, null)
